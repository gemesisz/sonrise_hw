# Alerting Service — take-home task

Implementation of the "Feature Design & Build from a Vague Brief" task: a
service where users configure alerts on world events, delivered via
pluggable channels (email, Slack, more later), with an admin view.

**This repo's structure is documentation of process, not just code.** See:

- [`PLAN.md`](PLAN.md) — the plan of attack: deliverables, order, and why,
  written before any code existed.
- [`DECISIONS.md`](DECISIONS.md) — running decision log: interpretations of
  the ambiguous brief, scope cuts, rejected AI output, course-corrections.
- [`PROMPTS.md`](PROMPTS.md) — chronological log of prompts used to direct AI
  during the build.
